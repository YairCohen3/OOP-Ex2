SmartClass — עדכון רענון אוטומטי / QR / OTP / סקרים / צילום כיתה
============================================================

קבצים להחלפה בתיקיית הפרויקט:
  index.html       — ממשק מלא עם עדכונים ועיצוב רספונסיבי
  main.py          — API מעודכן; יוצר אוטומטית טבלאות נתונים חדשות
  requirements.txt — ספריות הפרויקט + qrcode[pil] ליצירת QR עצמאית בשרת

קובץ רשות:
  requirements-vision.txt — התקנת YOLOv8 לספירת אנשים מדויקת יותר

חשוב:
1. גבו את הקבצים לפני ההחלפה.
2. אל תחליפו או תמחקו את smartclass.db, models.py או database.py.
3. השינויים ב-main.py מבוססים על גרסת השרת שעבדנו עליה בשיחה;
   אם קיימות אצלכם התאמות חדשות שלא נכללו, בצעו מיזוג לפני ההחלפה.

הרצה במחשב (מתוך תיקיית הפרויקט, ב-PyCharm Terminal):
--------------------------------------------------------
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

פתיחה במחשב: http://127.0.0.1:8000

צילום מהטלפון:
----------------
1. חברו את המחשב והטלפון לאותה רשת Wi-Fi.
2. ב-Windows, פתחו טרמינל והקלידו ipconfig. מצאו IPv4 Address,
   לדוגמה 192.168.1.27.
3. האתר ינסה להציע כתובת מקומית אוטומטית. אם היא לא מתאימה,
   במסך ההרצאה הזינו 'Server address visible to your phone':
   http://192.168.1.27:8000
4. סרקו עם הטלפון את ה-QR באזור CLASSROOM PHOTO,
   צלמו/בחרו תמונה ולחצו Analyze & send to lecturer.
5. אחרי ניתוח התמונה תוצג תוצאה מעודכנת אצל המרצה תוך עד 5 שניות.
6. אם אין גישה מהטלפון, אפשרו לפורט 8000 תקשורת ב-Windows Firewall.
7. QR הנוכחות הוא QR אחר, והוא מיועד לסריקה מתוך חשבון הסטודנט.

טיימרים ורענון:
---------------
- OTP: קוד תקף ל-120 שניות; מוצג שעון וניתן לבקש קוד מחדש.
- QR נוכחות: מתחלף כל 10 שניות, כולל פס התקדמות ושעון.
- נתוני קורס, שיעור, פורום, סקרים ונוכחות נבדקים כל 5 שניות.
- כפתור Refresh בכותרת מעדכן ידנית את המסך הנוכחי.
- Enter בשדה שם קורס יוצר את הקורס; Enter ב-OTP מתחבר.

ניתוח צילום:
------------
ברירת המחדל היא זיהוי אנשים אמיתי אך בסיסי באמצעות OpenCV HOG.
הוא עלול לפספס אנשים יושבים, ולכן התוצאה מוצגת כהערכה, ויש למרצה
אפשרות לתקן את הספירה ידנית לפני סיום הרצאה.

להפעלת YOLOv8 (רשות, מודל מוריד משקולות בהפעלה הראשונה):
python -m pip install -r requirements-vision.txt

Windows PowerShell:
$env:SMARTCLASS_ENABLE_YOLO="1"
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

אפשר גם להגדיר SMARTCLASS_YOLO_MODEL=yolov8n.pt.

מגבלות דמו ידועות:
-----------------
- הכניסה עדיין מחזירה קוד OTP למסך ואינה שולחת מייל אמיתי.
- מערכת המשתמשים והרשאות חלק מהנתיבים היא דמו; אינה מוכנה לפרודקשן.
- עדכונים כל 5 שניות הם polling, לא WebSocket בזמן אמת.
- זיהוי OpenCV HOG הוא אומדן. YOLO אופציונלי ולא נטען ללא התקנה.
- צילום עצמו אינו נשמר במסד הנתונים; נשמרת רק תוצאת הספירה והשיטה.
- Excel נשמר ב-attendance_reports/ ואפשר להוריד מתוך הרצאת עבר.
- Railway עם SQLite/קבצים מקומיים עשוי לאבד נתונים בעת פריסה מחדש.
- שימוש במצלמת סריקת QR בתוך דפדפן טלפון עשוי לדרוש HTTPS;
  לעומת זאת בחירת/צילום קובץ באמצעות input file יכולה לעבוד ברשת LAN.
- למספר שרתים/Workers יש להגדיר SMARTCLASS_QR_SECRET ערך קבוע זהה בכולם.
