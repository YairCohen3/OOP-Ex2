SmartClass — הוראות הרצה ופריסה
================================

הרצה במחשב (מתוך תיקיית הפרויקט, ב-PyCharm Terminal):
--------------------------------------------------------
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

פתיחה במחשב: http://127.0.0.1:8000

משתני סביבה:
------------
GEMINI_API_KEY        — חובה לפיצ'רי ה-AI (ספירת אנשים, סיכום וידאו, בדיקת מטלות, השוואה).
                        בלי מפתח המערכת מציגה "לא מוגדר" ולא ממציאה תוצאות.
GEMINI_MODEL          — רשות. ברירת מחדל: gemini-3.5-flash
GEMINI_FALLBACK_MODEL — רשות. מודל גיבוי כשהמודל הראשי עמוס. ברירת מחדל: gemini-3.5-flash-lite
SMARTCLASS_DATA_DIR   — תיקיית הנתונים (DB, קבצים שהועלו, דוחות Excel). ב-Railway: נתיב ה-Volume, למשל /data
SMARTCLASS_QR_SECRET  — מפתח קבוע ל-QR הדינמי (חובה אם יש יותר משרת/Worker אחד).

Windows PowerShell:
$env:GEMINI_API_KEY="..."
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

הרצת בדיקות:
-------------
python -m pytest -v
(הבדיקות רצות על DB זמני ריק — smartclass.db האמיתי לא נפגע.)

זרימת הנוכחות (הפיצ'ר המרכזי):
-------------------------------
1. המרצה פותח שיעור — מוקרן QR דינמי שמתחלף כל 10 שניות.
2. הסטודנטים סורקים מתוך החשבון שלהם בטלפון.
3. SESSION END — נעילת הסריקות.
4. צילום הכיתה (מהמחשב, או מהטלפון דרך QR הצילום) — Gemini סופר אנשים.
   המרצה יכול לתקן את הספירה ידנית. אם ה-AI נכשל, מתבקשת ספירה ידנית.
5. הצלבה: יותר סריקות מאנשים → אזהרה + (א) התחלת נוכחות מחדש (ב) צילום חוזר (ג) אישור וייצוא.
   אנשים ≥ סריקות → הרשימה תקינה.
6. אישור → קובץ Excel (שם, מייל מוסדי, זמן, סטטוס — בלי ת"ז), זמין להורדה גם משיעור עבר.

צילום מהטלפון ברשת מקומית:
--------------------------
1. חברו את המחשב והטלפון לאותה רשת Wi-Fi.
2. ב-Windows: ipconfig → IPv4 Address (למשל 192.168.1.27).
3. במסך ההרצאה, אם הכתובת שהוצעה לא מתאימה, הזינו: http://192.168.1.27:8000
4. סרקו בטלפון את ה-QR באזור CLASSROOM PHOTO, צלמו ושלחו.
5. אם אין גישה מהטלפון — אפשרו פורט 8000 ב-Windows Firewall.
שימו לב: QR הנוכחות ו-QR הצילום הם שני קודים שונים.

טיימרים ורענון:
---------------
- OTP: תקף 120 שניות, עם שעון וכפתור לשליחה מחדש.
- QR נוכחות: מתחלף כל 10 שניות (+2 שניות חסד), עם פס התקדמות.
- נתוני שיעור, פורום, סקרים ונוכחות מתעדכנים כל 5 שניות; כפתור Refresh לרענון ידני.

מגבלות דמו ידועות:
-----------------
- קוד ה-OTP מוצג על המסך לצורך הדמו ואינו נשלח במייל.
- רשימת המשתמשים המורשים מוגדרת בקוד (AUTH_USERS ב-main.py).
- ההרשאות מבוססות על המייל שנשלח בכל בקשה (אין token של session) — מתאים לדמו בלבד.
- העדכונים הם polling כל 5 שניות, לא WebSocket.
- תמונת הכיתה לא נשמרת — נשמרים רק הספירה ושיטת הספירה.
- מצלמת סריקת QR בדפדפן טלפון דורשת HTTPS (עובד ב-Railway). ברשת מקומית אפשר להעלות קובץ.
- קישור הקלטה ישיר נתמך כרגע רק ל-YouTube ציבורי; הקלטות Zoom/Classroom מעלים כקובץ (עד 500MB).

פריסה ב-Railway:
-----------------
1. Push ל-GitHub — Railway פורס אוטומטית.
2. הגדירו Volume והגדירו SMARTCLASS_DATA_DIR לנתיב שלו (אחרת הנתונים נמחקים בפריסה מחדש).
3. הגדירו GEMINI_API_KEY ב-Variables.
4. אחרי פריסה: Ctrl+F5 בדפדפן כדי לקבל HTML עדכני.
